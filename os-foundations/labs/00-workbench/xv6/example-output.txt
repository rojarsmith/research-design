Recorded 2026-11-16 in an Ubuntu 24.04.5 container (image oslab:24.04) under
rootless podman 5.8.3 on Windows 11 Pro build 26300. The podman machine runs
on WSL 2 (kernel 6.6.87.2-microsoft-standard-WSL2). This is not the WSL 2
Ubuntu distribution that the lab's setup step 1 installs.
xv6-riscv master, commit fa2ddcb7ca87a77af579380a6eafd5aff163b44f
(2026-11-05, "usertests: bound the zero-length pipe read regression test"),
copied to /tmp/x inside the container and built there as root (uid 0, so
GDBPORT is 25000).
GDB was driven by batch scripts (gdb-multiarch -q -batch -x <script>) against
"make CPUS=n qemu-gdb" running in the background of the same container.
Batch GDB does not echo commands, so the "(gdb) ..." lines below are the
script's commands, put in front of the output they produced. Lines marked
[...] were cut, and notes in parentheses were added; nothing else was
edited. Carriage returns from the QEMU console were removed.
