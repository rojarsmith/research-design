Recorded 2026-11-16 in an Ubuntu 24.04.5 container (image oslab:24.04) under
rootless podman 5.8.3 on Windows 11 Pro build 26300. The podman machine runs
on WSL 2 (kernel 6.6.87.2-microsoft-standard-WSL2). This is not the WSL 2
Ubuntu distribution that the course tells you to use.
QEMU 8.2.2, riscv64-linux-gnu-gcc 13.3.0, gdb-multiarch 15.1.
xv6-riscv master, commit fa2ddcb7ca87a77af579380a6eafd5aff163b44f
(2026-11-05), built in /tmp/x inside the container. MIT's xv6-labs-2025
repository was not used.
Exercise C ran against a trapinfo() written only for this check; that
kernel code is not in this folder.
GDB was driven by batch scripts. Batch GDB does not echo commands, so the
"(gdb) ..." lines are the script's commands, put in front of their output.
Some commands ran through a small Python wrapper that catches GDB errors;
those error messages are shown without the wrapper's "[gdb error]" prefix.
Lines marked [...] were cut, and notes in parentheses were added; nothing
else was edited. Carriage returns from
the QEMU console were removed.
