Recorded 2026-11-16 in an Ubuntu 24.04 container (image oslab:24.04) under
podman 5.8.3 on Windows 11 build 26300 (Intel Core i7-11700). The podman
machine is a WSL 2 VM, so the kernel is WSL's 6.6.87.2-microsoft-standard-WSL2
and every timing here is a VM number. This is not WSL 2 Ubuntu itself.
Tools in the image: QEMU 8.2.2, riscv64-linux-gnu-gcc 13.3.0, gdb-multiarch
15.1, gcc 13.3.0, expect. xv6-riscv at fa2ddcb7ca87a77af579380a6eafd5aff163b44f
(2026-11-05), copied to /tmp in the container before patching.
The lab folder was mounted read-only at /work. SOLUTION_DIR pointed at the
reference solutions, which are not shipped. Your numbers will differ.
