# AI assisted team software development

Research date: 2026-10-18. This is an English overview; the [complete study is in Traditional Chinese](README.zh-TW.md).

The study covers practical Git and GitHub collaboration for teams and departments, with GitLab and Azure DevOps alternatives. Its proposed baseline is a protected main branch, short-lived task branches, accountable human owners, independent review, real CI evidence, and traceable release artifacts. AI contributes within the same process.

The complete study includes an end-to-end product delivery example, repository organization, branch retention and deletion decisions, squash merge caveats, worktree cleanup, release maintenance, hotfixes, AI permissions, platform gates, reusable templates, and official references. Proposed operating policies are distinguished from documented product behavior.
