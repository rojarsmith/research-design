# Winstar Smart Display Research

Research date: October 21, 2026, Asia/Taipei.

The existing [MCU embedded HMI study](../mcu-embedded-hmi-research/README.md) already covers Winstar's CAN displays. This separate study extends coverage to the Smart Display portfolio, RS485/Modbus, proprietary UART, GUI Builder, representative modules, and integration constraints. It also rechecks the requested CAN category.

- [Portfolio comparison and representative modules](README.zh-TW.md)
- [GUI Builder capabilities and integration evaluation](research/01-gui-builder-and-integration.zh-TW.md)
- [Sources, coverage audit, and unresolved specification differences](research/02-sources-and-open-questions.zh-TW.md)

Vendor specifications are distinguished from engineering judgments. The research applies the same evidence standard to Winstar, EDT, and other vendors. It does not establish measured performance or production reliability.
