# 鼻子不定時聞到鐵鏽味：可能原因與就醫科別

**研究日期：2026-11-20（台灣時間）**
**問題：** 鼻子不定時聞到鐵鏽味（金屬味、血腥味），可能是什麼病？該看哪一科？

> 本文件整理公開醫療衛教資料，屬一般資訊，不是診斷，也不能取代醫師面診。若出現下方「立即就醫」的情況，請直接到急診。各項說法的出處見 [sources.md](sources.md)，標示「一般醫學常識」者未在本次來源中逐字查核。

## 結論先看

1. **先看耳鼻喉科。** 聞到怪味最常見的原因在鼻子與鼻竇；耳鼻喉科能用鼻咽內視鏡直接看鼻腔深處與鼻咽，必要時再安排電腦斷層或核磁共振。中國醫藥大學附設醫院、Hello醫師（北醫附醫耳鼻喉科醫師審稿）與 Cleveland Clinic 都把耳鼻喉科列為主要就診科別。
2. **「鐵鏽味」要先分兩種：** 一種是**真的有血**（血液含鐵，聞起來、嚐起來像鐵鏽），例如鼻黏膜微量出血、牙齦出血、鼻咽或鼻竇病灶滲血；另一種是**幻嗅**（phantosmia）——周遭沒有這個氣味，大腦卻感覺到。金屬味是幻嗅常見的描述之一。
3. **多數原因良性、會自行消退。** Cleveland Clinic 與 NHS（nidirect）都說，感冒、鼻竇炎、過敏引起的幻嗅通常幾週內消失；**超過約三週仍反覆出現就該就醫**。
4. **少數原因需要排除：** 顳葉癲癇的嗅覺先兆、偏頭痛、頭部外傷、腦瘤、中風、帕金森症等神經原因（此時改看或加看**神經內科**）；台灣屬鼻咽癌高發地區，若同時有**鼻涕或痰常帶血絲、單側鼻塞、單側耳悶、頸部無痛腫塊**，且超過兩週不改善，應儘快讓耳鼻喉科檢查鼻咽。
5. **並不罕見。** 美國 NHANES 2011–2014 調查 7,417 位 40 歲以上成人，6.5% 表示曾聞到不存在的氣味，但其中只有約 11% 跟醫師提過嗅覺或味覺問題（Bainbridge 等，2018）。

## 名詞

| 名詞 | 意思 |
|---|---|
| 幻嗅（phantosmia） | 環境中沒有該氣味，卻聞到；常被描述為燒焦、腐臭、化學品或金屬味 |
| 嗅覺倒錯（parosmia） | 真實存在的氣味被扭曲成難聞的味道，常見於感冒或新冠感染後 |
| 嗅覺異常（dysosmia） | 上述兩者的統稱；MSD Manual 使用此詞與「嗅覺幻覺」 |
| 味覺異常（dysgeusia） | 嘴裡有金屬、苦、腐敗等異味；因嗅覺與味覺共同構成「風味」，嘴裡的金屬味有時會被感覺成「聞到」 |

## 第一步：分辨是真的有血，還是幻嗅

下表是依來源整理的觀察方向，用來決定先掛哪一科，不能自行診斷。

| 你觀察到的線索 | 可能方向 | 優先科別 |
|---|---|---|
| 擤鼻涕或早上第一口痰見到血絲；鼻孔內有血痂 | 真的有血：鼻黏膜乾燥破損、鼻炎、鼻竇炎；長期或單側則需排除鼻咽病灶 | 耳鼻喉科 |
| 刷牙或用牙線時牙齦出血、牙齦腫痛、口臭 | 牙齦炎、牙周病、牙齒感染（血的鐵味） | 牙科 |
| 嘴裡也一直有金屬味，不只鼻子 | 味覺異常：藥物、保健品（鋅、鐵、綜合維他命）、牙周、懷孕、代謝疾病 | 家醫科或開藥的醫師；牙周問題看牙科 |
| 最近感冒、流感、新冠或鼻塞、黃鼻涕 | 感染後或鼻竇炎造成的幻嗅或嗅覺倒錯 | 耳鼻喉科 |
| 最近開始吃新藥（例如 metronidazole、clarithromycin、metformin、lithium、allopurinol 等） | 藥物副作用 | 開藥的醫師或藥師（**不要自行停藥**） |
| 每次只持續幾秒到幾分鐘，伴隨恍神、似曾相識感、胃部往上湧的感覺、事後記不清（後三項為一般醫學常識） | 顳葉癲癇的嗅覺先兆 | 神經內科 |
| 怪味和頭痛一起出現 | 偏頭痛相關 | 神經內科 |
| 頭部受過撞擊後才開始 | 頭部外傷 | 神經內科／神經外科，並告知耳鼻喉科 |
| 只在特定地點出現（老舊水管、工地、焊接、金屬加工、化學品） | 可能是真實的環境氣味或化學物質暴露（鉛、汞、殺蟲劑） | 先排除環境；疑似職業暴露看職業醫學科 |

**可以自己先做的小測試（一般醫學常識，非來源原文）：** 聞到時輪流按住單側鼻孔，記錄是哪一側、按住後是否消失。Cleveland Clinic 指出醫師會問「是哪一側或兩側鼻孔」，這項紀錄對醫師判斷有幫助。

## 可能原因整理

### 常見（多半良性、可治療）

| 原因 | 說明 | 來源 |
|---|---|---|
| 感冒、流感、上呼吸道感染、新冠 | 病毒可能損傷嗅覺上皮或嗅神經；多數幾週到幾個月內改善 | Cleveland Clinic、nidirect、Hello醫師、Harvard Health |
| 急性或慢性鼻竇炎 | 細菌積存在鼻竇，會聞到臭味或特殊異味，吞嚥時也可能感覺到；輕者用鼻噴類固醇、洗鼻或抗生素，重者做鼻竇內視鏡手術 | 安南醫院劉金瑞醫師（TVBS 報導）、Hello醫師 |
| 過敏性鼻炎、鼻息肉、鼻中膈彎曲 | 傳導性嗅覺障礙，治療原因後較有機會改善 | 中國附醫衛教、Hello醫師、Cleveland Clinic |
| 鼻黏膜乾燥導致的微量出血 | 冷氣、暖氣或乾燥氣候會讓鼻黏膜乾裂，鼻中膈前端容易出血；少量出血可能看不到，卻聞得到血味 | NHS（鼻出血）；「看不到出血卻聞到血味」屬推論 |
| 牙齦炎、牙周病、牙齒感染、口乾 | 牙齦出血帶來鐵味；口乾與幻嗅有關（NHANES 研究中持續口乾者的幻嗅勝算比約 3 倍） | Cleveland Clinic、Bainbridge 2018 |
| 藥物與保健品 | 抗生素（metronidazole 最常見，也可能造成金屬「氣味」）、降血壓藥 captopril、lithium、metformin、allopurinol、抗憂鬱藥；含鋅、銅、鉻的綜合維他命、鐵劑、鈣片、產前維他命 | Harvard Health、Cleveland Clinic |
| 抽菸 | 列於幻嗅常見原因 | Cleveland Clinic |
| 懷孕 | 嗅覺過敏與味覺異常常見，多在第一孕期後改善 | MSD Manual、Cleveland Clinic |
| 焦慮、憂鬱等心理因素 | 列於幻嗅原因之一 | Harvard Health、nidirect |

### 較少見、需要排除

| 原因 | 特徵 | 來源 |
|---|---|---|
| 顳葉癲癇（嗅覺先兆） | 短暫、反覆、常是難聞或金屬味，可能接著出現發作；需要腦波（EEG）與 MRI | MSD Manual、Cleveland Clinic |
| 偏頭痛 | 怪味可在頭痛前或頭痛時出現 | Cleveland Clinic、nidirect、Harvard Health |
| 頭部外傷 | NHANES 研究中曾因頭部受傷失去意識者，幻嗅勝算比約 1.7 倍；外傷造成的嗅覺障礙藥物效果有限，嗅神經可能數年內慢慢再生 | Bainbridge 2018、Hello醫師 |
| 腦瘤、中風、帕金森症、阿茲海默症 | Cleveland Clinic 列為較少見原因 | Cleveland Clinic |
| 鼻腔、鼻竇或鼻咽腫瘤（含鼻咽癌） | 鼻涕或痰常帶血絲、單側鼻塞超過兩週、單側耳悶或聽力下降、頸部無痛腫塊、頭痛、臉部麻木；台灣為高發地區，多與 EB 病毒有關，早期治癒率可達九成以上 | TVBS 報導引述耳鼻喉科醫師著作、Hello醫師 |
| 腎臟病、肝病、未診斷的糖尿病 | 主要造成嘴裡金屬味，通常同時有其他症狀（水腫、疲倦、尿量改變等）；只有金屬味而無其他症狀時通常是良性 | Cleveland Clinic |
| 化學物質或重金屬暴露 | 鉛、汞、殺蟲劑；Cleveland Clinic 建議有暴露者立即就醫 | Cleveland Clinic |

## 什麼時候要就醫

### 立即就醫（急診）

- 出現抽搐、意識中斷、突然無法說話或口齒不清、單側手腳無力或麻木、臉歪、突發劇烈頭痛、視力突然改變——這些是癲癇或中風的警訊（一般醫學常識）。
- 頭部撞擊後才出現怪味，且伴隨頭痛加劇、嘔吐、嗜睡或意識改變（一般醫學常識）。
- 流鼻血壓迫 10–15 分鐘仍止不住，或出血量很大（NHS）。
- 接觸過鉛、汞、殺蟲劑等化學物質後出現（Cleveland Clinic）。

### 儘快排門診

- 怪味持續或反覆超過約三週（Cleveland Clinic；NHS 寫「幾週」）。
- 鼻涕或痰常帶血絲、單側鼻塞、單側耳悶或耳鳴、頸部摸到不痛的腫塊，其中任一項持續超過兩週，或同時出現兩項以上 → 耳鼻喉科，請醫師檢查鼻咽（TVBS 報導引述耳鼻喉科醫師）。
- 經常流鼻血、正在吃抗凝血藥、或有貧血症狀（心跳快、喘、臉色蒼白）（NHS）。
- 嗅覺同時明顯變差或消失。
- 嘴裡金屬味伴隨水腫、疲倦、尿量改變等其他症狀（Cleveland Clinic）。

## 看哪一科：建議路線

| 順序 | 科別 | 何時看 | 可能的檢查 |
|---|---|---|---|
| 1 | **耳鼻喉科**（首選） | 大多數情況；有鼻塞、血絲、鼻涕、耳悶時一定先看 | 問診、鼻腔與鼻咽內視鏡、嗅覺測試（如刮刮聞測試）、必要時鼻竇電腦斷層或核磁共振 |
| 2 | **神經內科** | 耳鼻喉科檢查正常但仍反覆；或伴隨頭痛、恍神、記憶空白、抽搐、頭部外傷史 | 神經學檢查、腦波（EEG）、腦部核磁共振 |
| — | 牙科 | 牙齦出血、牙痛、口臭 | 牙周檢查、X 光 |
| — | 家醫科 | 不確定掛哪科、症狀多樣、或嘴裡也有金屬味 | 用藥檢視、抽血（血球、腎功能、肝功能、血糖、鐵、維生素 B12 等，Cleveland Clinic 列於味覺異常的檢查）並協助轉診 |
| — | 身心科 | 已排除生理原因，且合併明顯焦慮、憂鬱 | 評估與治療 |

部分醫學中心耳鼻喉科設有嗅覺相關門診，可在醫院網站查詢；台灣嗅覺核磁共振等專門設備相對少，客觀嗅覺檢查也有限（康健知識庫）。

## 就醫前先記錄

看診時間短，事先記錄能讓醫師較快判斷。建議連續記錄一到兩週：

| 欄位 | 範例 |
|---|---|
| 日期、時間 | 11/20 早上 7:30 |
| 持續多久 | 約 2 分鐘 |
| 哪一側 | 左側；按住左鼻孔後消失／不消失 |
| 當時在做什麼、在哪裡 | 剛起床、擤鼻涕後；在辦公室冷氣房 |
| 伴隨症狀 | 鼻涕帶血絲、鼻塞、耳悶、頭痛、恍神、似曾相識感、嘴裡也有金屬味 |
| 近期變化 | 感冒、新冠、新藥或保健品、牙科治療、頭部撞擊、搬家或換工作環境 |

一併帶上目前所有藥物與保健品清單（含鋅、鐵、綜合維他命）。

## 等待就醫期間的自我照護

- 以生理食鹽水洗鼻，Cleveland Clinic 與 NHS 都列為居家方法；Cleveland Clinic 另提到可短期使用 oxymetazoline 鼻噴劑，但這類血管收縮噴劑連續使用多日可能造成反彈性鼻塞（一般醫學常識），使用前先問醫師或藥師。
- 冷氣房或冬天保持室內不過度乾燥，避免挖鼻、用力擤鼻（NHS：乾燥與挖鼻是鼻出血常見原因）。
- 加強口腔衛生、定期洗牙。
- **不要自行停用處方藥**；懷疑藥物造成時先問開藥醫師或藥師。
- 戒菸。
- 感冒或新冠後嗅覺變差或扭曲，耳鼻喉科醫師常建議嗅覺訓練（每天早晚聞玫瑰、尤加利、檸檬、丁香各 20–30 秒，持續至少 24 週）；此法針對嗅覺喪失或倒錯，不是幻嗅的專門治療。

## 預後

- 感染、鼻竇、過敏造成者：治療或痊癒後通常停止，多在幾週內（Cleveland Clinic）；也可能持續數月，少數成為永久（nidirect）。
- 神經原因造成者：可能持續較久，甚至數年，需針對原因治療（例如癲癇用藥或手術）（Cleveland Clinic）。
