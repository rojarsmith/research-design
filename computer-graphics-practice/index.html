Your experiments

Predict first. Change one thing. Explain the pixels you get.

02 / A

Set Rotate to 90° and Translate X to 3. Predict where the F lands, then switch between T · R · S and R · T · S. Which order swings the F around the world origin?

02 / B

Drag Scale X below zero. The F mirrors and every signed area changes sign. Does it still fill? What does the determinant say?

02 / C

Set Scale X = 2, Scale Y = 0.5 and Rotate = 45°. Compare T · R · S with T · S · R. Which order stops right angles from staying right angles, and why?

02 / D

Compare the red and green local axes with the first two columns of M, and the orange dot with the third. Why is the pixel-space area negative even when nothing is mirrored?

Core rule
With column vectors, M = T · R · S applies S first. Keep object, world and pixel coordinates as separate, named spaces; each arrow between two spaces is one matrix.
