Core rule
Perspective is a division. The projection matrix copies −z_view into w, and NDC = clip ÷ w. Every step before the divide is a matrix product.

Core rule
Visibility is decided per sample, not per triangle: each pixel keeps the nearest depth seen so far. Clipping and culling decide which triangles reach the rasterizer at all.

Core rule
