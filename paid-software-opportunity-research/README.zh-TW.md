# 哪些軟體適合做成付費產品

研究日期：2026-11-03（Asia/Taipei）。問題：除了 Markdown 編輯器，還有哪些軟體適合做成付費產品？本文是判斷框架與方向建議，延續[付費 Markdown 編輯器市場研究](../markdown-editor-market-research/README.zh-TW.md)；收費與授權做法見[桌面軟體收費研究](../desktop-licensing-research/README.zh-TW.md)。

## 結論

**會有人付錢的軟體，通常幫「有預算的人」解決「跟錢、截止日或法規有關」的問題，而且免費工具和 AI 隨手生成的小工具都做不好。** 編輯器、筆記、待辦清單、格式轉換等個人工具，三點都不符合。

對照本 repo 的既有研究，優先建議發展 **Bitdove OTA 加歐盟 CRA 合規**：B2B、有法定截止日推動需求、有持續服務價值，而且已有研究基礎。開始前需先確認與任職公司的權利歸屬沒有衝突。

## 判斷條件

符合越多條，越適合收費：

| 條件 | 為什麼重要 |
| --- | --- |
| 付錢的是公司或專業人士 | 公司花的是預算；個人用戶對 $15 都會猶豫 |
| 痛點連到錢、截止日或法規 | 省工時、避免罰款、趕上交期，價值容易計算 |
| 免費替代品不夠用 | 開源方案要自架自維護，或沒人做這個領域、這個地區 |
| 需要持續的價值 | 有雲端服務、資料更新或法規變動，訂閱才有理由 |
| 有 AI 難以一次生成的門檻 | 領域知識、硬體整合、資料、認證、通路；2026 年做簡單工具的門檻已經很低 |
| 自己有優勢 | 懂這個領域、認識買家，比功能多更重要 |

## 比較適合收費的類別

| 類別 | 例子 | 收費方式 |
| --- | --- | --- |
| 特定產業的 B2B 工作流程 | 工廠設備保養紀錄、診所排班、代工廠出貨文件 | 每家公司訂閱 |
| 大型軟體的外掛 | Revit、AutoCAD、Blender、Figma、Excel 外掛 | 買斷或年費；買家習慣在這些平台買外掛 |
| 硬體周邊軟體 | 設備設定工具、CAN／Modbus／UART 除錯、韌體燒錄與 OTA | 與硬體綁定，或按工程師席位收費 |
| 法規與合規工具 | 歐盟 CRA 的 SBOM 與弱點通報、資安證據整理 | 年費；有法定截止日，買家會主動找 |
| 系統串接 | 台灣電子發票、綠界或藍新串接 Shopify／WooCommerce、ERP 資料同步 | 月費；串接中斷時客戶立刻受影響 |
| 本機或私有部署的 AI | 不能把資料上雲的公司使用的文件處理與檢索 | 授權費加維護費 |
| 在地化缺口 | 台灣勞健保、公文、統一發票相關工具 | 市場小，但競爭少 |

## 比較不適合的類別

- **通用消費型工具**：免費替代品多，AI 也做得出來。
- **靠網路效應的產品**：社群、市集等需要大量使用者才有價值。
- **平台方隨時能內建的功能**：作業系統或 Office 一更新就免費提供。

### CRA 的時程

依 [CRA 範圍與符合性研究](../eu-ota-cra-sales-research/research/02-cra-scope-and-conformity.zh-TW.md)（法規本文為 Regulation (EU) 2024/2847）：

- **2026-09-11 起**：製造商須通報受 CRA 涵蓋產品中遭主動利用的弱點與嚴重事件，範圍包含既有產品。
- **2027-12-11 起**：大部分產品義務適用。

中小型設備商需要有人把 OTA、簽章、SBOM 與弱點處理一次做好，這是願意付年費的需求。對外說法需遵守 CRA 研究中的限制，例如不宣稱「ETSI CRA 認證」。

### 權利歸屬要先確認

[Claude Startups 研究](../claude-startups-research/README.zh-TW.md)記錄 HMI Studio 是任職的 EDT 公司產品。個人若要做嵌入式或 HMI 相關的付費軟體，先確認：

- 勞動契約中的智慧財產歸屬與競業條款。
- 是否使用工作時間、公司設備或公司資料。
- 產品是否與公司現有或規劃中的產品重疊。

有疑慮時，先取得公司書面同意，或請律師審閱。
