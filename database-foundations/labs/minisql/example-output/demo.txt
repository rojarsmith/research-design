
== 0. 範例資料 ==
cities：6 列（name TEXT, region TEXT）；索引：無
customers：200 列（id INT, name TEXT, city TEXT）；索引：customers_id
orders：3,000 列（id INT, customer_id INT, amount INT, status TEXT, day INT）；索引：orders_customer_id

== 1. SQL 原文 ==
SELECT c.city, COUNT(*) AS n, SUM(o.amount) AS total
FROM customers c JOIN orders o ON o.customer_id = c.id
WHERE o.status = 'paid' AND c.city <> 'Tainan'
GROUP BY c.city
HAVING COUNT(*) > 200
ORDER BY total DESC
LIMIT 3

== 5. 最佳化器改寫成等價但較便宜的實體計畫 ==
Limit 3  [est 2]
└─ Project c.city, count(*) AS n, sum(o.amount) AS total  [est 2]
   └─ Sort sum(o.amount) DESC  [est 2]
      └─ Filter count(*) > 200  [est 2]
         └─ HashAggregate GROUP BY c.city: count(*), sum(o.amount)  [est 6]
            └─ HashJoin o.customer_id = c.id  (hash table built on the 2nd input)  [est 597]
               ├─ Filter o.status = 'paid'  [est 750]
               │  └─ SeqScan orders AS o  [est 3,000]
               └─ Filter c.city <> 'Tainan'  [est 160]
                  └─ SeqScan customers AS c  [est 200]

- 下推：o.status = 'paid' 只用到 o，移到 o 的掃描正上方
- 下推：c.city <> 'Tainan' 只用到 c，移到 c 的掃描正上方
- 連接順序：先取估計列數最小的 c（約 160 列）
- 接上 o：有等值條件 o.customer_id = c.id，用 HashJoin，雜湊表建在估計較小的 c 一側
