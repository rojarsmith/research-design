兩表連接、篩選、分組（與 demo 相同）
SELECT c.city, COUNT(*) AS n, SUM(o.amount) AS total
FROM customers c JOIN orders o ON o.customer_id = c.id
WHERE o.status = 'paid' AND c.city <> 'Tainan'
GROUP BY c.city
HAVING COUNT(*) > 200
ORDER BY total DESC
LIMIT 3

== 未最佳化（依定義翻譯） ==
Limit 3  [est 2, actual 3]
└─ Project c.city, count(*) AS n, sum(o.amount) AS total  [est 2, actual 3]
   └─ Sort sum(o.amount) DESC  [est 2, actual 3]
      └─ Filter count(*) > 200  [est 2, actual 5]
         └─ HashAggregate GROUP BY c.city: count(*), sum(o.amount)  [est 6, actual 5]
            └─ Filter o.status = 'paid' AND c.city <> 'Tainan'  [est 597, actual 1,323]
               └─ Filter o.customer_id = c.id  [est 2,985, actual 2,988]
                  └─ NestedLoopJoin ×  [est 600,000, actual 600,000]
                     ├─ SeqScan customers AS c  [est 200, actual 200]
                     └─ SeqScan orders AS o  [est 3,000, actual 3,000]
所有運算子合計產出 607,530 列；耗時 227.6 ms；結果 3 列

== 最佳化後 ==
Limit 3  [est 2, actual 3]
└─ Project c.city, count(*) AS n, sum(o.amount) AS total  [est 2, actual 3]
   └─ Sort sum(o.amount) DESC  [est 2, actual 3]
      └─ Filter count(*) > 200  [est 2, actual 5]
         └─ HashAggregate GROUP BY c.city: count(*), sum(o.amount)  [est 6, actual 5]
            └─ HashJoin o.customer_id = c.id  (hash table built on the 2nd input)  [est 597, actual 1,323]
               ├─ Filter o.status = 'paid'  [est 750, actual 1,621]
               │  └─ SeqScan orders AS o  [est 3,000, actual 3,000]
               └─ Filter c.city <> 'Tainan'  [est 160, actual 163]
                  └─ SeqScan customers AS c  [est 200, actual 200]
所有運算子合計產出 6,326 列；耗時 3.2 ms；結果 3 列

兩個計畫的結果相同：True

SELECT ci.region, COUNT(*) AS n FROM cities ci, orders o, customers c
WHERE o.customer_id = c.id AND c.city = ci.name AND ci.region = 'South'
GROUP BY ci.region

         ├─ NestedLoopJoin ×  [est 18,000, actual 18,000]
