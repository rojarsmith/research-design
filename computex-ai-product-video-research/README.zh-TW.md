# EDT HMI Studio Computex AI 影片製作規劃

研究日期：2026 年 10 月 25 日。狀態：規劃與製作文件已建立；尚未連接影音帳號、付費生成素材或輸出成片。

本案以 **Claude 擔任影音製作指揮，經 MCP 操作雲端平台** 為主方案。Claude 負責企劃、分鏡、呼叫生成工具、安排剪輯與字幕、追蹤渲染及依回饋修改；人員負責錄製真實產品操作、審核產品主張、試聽聲音及在實際螢幕驗收。

建議先做一段 **20 秒驗證片**，確認 Claude 能真正完成「取用素材 → 生成聲音 → 雙語排版 → 雲端剪輯 → 下載 MP4 → 局部修改重出」，再製作 90 秒產品主片及 30 秒吸睛循環版。核心畫面使用真實 EDT HMI Studio 錄屏與實機攝影；生成影片只用於不承載功能證據的背景或過場。

## 已知需求與暫定設定

| 項目 | 設定與狀態 |
| --- | --- |
| 產品及用途 | EDT HMI Studio，台北 Computex 現場產品介紹 |
| 製作方式 | 使用者偏好雲端 AI 影音平台；Claude 經 MCP 指揮製作 |
| 字幕 | 英文與繁體中文，主片同時顯示，另存兩個獨立字幕檔 |
| 螢幕 | 約 50 吋；方向、型號與播放設備待定，先按橫式 16:9 |
| 解析度 | 同時交付 3840×2160 與 1920×1080；不把低解析素材放大當成原生 4K |
| 聲音 | 暫定英語旁白，雙語字幕；中文配音為選配。現場另有完全靜音版 |
| 展期 | 屆次未確認；暫用官方公布的 2027 年 6 月 1–4 日作倒排基準，非使用者已確認 |
| 預算 | 未定；先提出試作及正式製作估算，不購買訂閱 |
| 片長 | 建議 90 秒主片、30 秒循環版；3 分鐘技術片留作第二階段 |

展期來源：[COMPUTEX 官方網站](https://www.computextaipei.com.tw/en/index.html)。字級、片長、觀看距離與驗收數值均為本案設計起點，不是主辦單位規定。

## 主方案

| 工作 | 優先方案 | 原因與限制 |
| --- | --- | --- |
| 指揮與企劃 | Claude＋專案文件＋MCP | 將產品證據、腳本與可操作工具放在同一流程；實際工具權限需連線驗證 |
| 時間軸與輸出 | Creatomate 官方 MCP | 有可編輯模板、渲染工具及字幕／字型文件，適合雙語與版本反覆修訂 |
| 雲端剪輯備選 | Shotstack 官方 MCP | 官方提供組合與渲染介面；4K 需選支援的方案 |
| AI 語音及音效 | ElevenLabs 官方 MCP，驗證可用工具後採用 | 官方有創作能力入口，但同站 Agents 文件與創作頁範圍不同，必須實際列出工具再承諾自動化 |
| AI 配樂 | 先以 Firefly 網頁生成、下載後交 Claude 組裝 | 已查到音樂功能；本次未確認可直接用的官方 Firefly 音樂 MCP。若要求配樂也全 MCP，改評估 ElevenLabs Music 的公司資格與授權 |
| AI 生成過場 | 選配 Runway 官方 MCP | 能生成影像／影片，不取代精確產品 UI 或完整剪輯時間軸 |
| 最後修整與備援 | DaVinci Resolve 或 Premiere | 雲端工具不支援的混音、字幕微調及播放相容性補救 |

這是基於文件能力與本案需求的選型，尚非實測勝負。雲端平台不必全部訂閱：先驗證一個剪輯平台與一個聲音平台，其他按缺口添加。詳見[工具研究](research/01-tools.zh-TW.md)及[Claude 指揮流程](research/02-claude-mcp.zh-TW.md)。

## 影片要讓觀眾看懂什麼

建議主軸是「從畫面設計，到看得見的設備互動」。觀眾在任意時間加入觀看，都應在約 10 秒內知道產品名稱、用途及下一步可做什麼。主片展示設計／AI 輔助、狀態連動、實機操作三個環節；每項功能必須在拍攝版本可重現。

洗衣機是目前有既有腳本與影片檔案的示範候選，並非產品只適用家電的定位。若改用咖啡機或工業控制，沿用相同「操作 → 資料／狀態 → 畫面回應」結構。

不在片中使用無實測的「效率提升 90%」「支援任何 MCU」「完全免工程」「量產就緒」等主張。AI 製作影片與產品自身具備 AI 功能是不同事情；後者需單獨驗證。

## 下一個可執行里程碑

依官方價目試算，1080p 試作可先留約 **NT$2,000**，正式影片工具預算約 **NT$8,000／月**，跨兩個計費月約 **NT$16,000**。這是單人製作、配樂可人工匯入、以 US$1＝NT$33 假設並含約 20% 準備金的預留額；不含人力、設備、額外稅費及企業音樂合約。若所有配樂也必須由 Claude 經 MCP 生成，先取得適用公司方案的報價。詳見[完整費用表](research/04-feature-cost-budget.zh-TW.md)。

用一段已允許公開的產品錄屏，加英文與繁體中文文字，製作 20 秒測試片。先讓 Claude 讀取平台文件、列出工具與做免費驗證，再於確定預算範圍內渲染。測試字型、語音、素材上傳、4K 成本，以及「只改一句字幕」是否能正確重出。

影片規格已足夠啟動此試作的準備。正式渲染前才需補齊平台帳號／預算、可公開素材、產品版本；片尾定稿前補展位號碼、正式 CTA 網址與 QR code。不得將模板中的空值當成最終畫面。
