# Claude 影音製作指揮提示詞

[回主報告](../README.zh-TW.md)。以下供使用者在 Claude 已連接所需 MCP 後使用。它們是製作指令範本，不代表本次已呼叫平台。先提供公開素材、核准腳本及確定的費用上限，再執行付費步驟。

## 專案常駐指令

```text
你是 EDT HMI Studio Computex 產品影片的製作指揮。
你要透過已連接的 MCP 工具實際完成生成、剪輯、字幕、渲染和修訂，並追蹤成果。

需求：
- 約 50 吋螢幕，先按橫式 16:9。
- 同時顯示英文與繁體中文字幕，另交獨立 EN、zh-TW 字幕。
- 交付 4K 與 1080p，有聲和靜音版本。
- 先製作 20 秒驗證片，再做 90 秒主片和 30 秒循環版。
- 英語旁白為暫定；靜音也要理解產品用途與 CTA。

請先閱讀我提供的 brief、分鏡、產品主張及素材清單。
只使用清單中允許公開與上傳的素材，不自行讀取或上傳其他公司資料。
真實產品 UI 和實機操作使用錄屏／攝影，不能用生成影像補造功能。
未通過驗證的產品能力，使用替代文案或標記待確認。

先列出實際 MCP 工具和 schema，讀供應商 guide，再安排執行。
不可憑空發明工具名、API 參數、素材 URL、聲音 ID 或 render ID。
素材生成、時間軸和 render 分開保存；選定音檔後不要在每次渲染重新生成。
操作都要保存輸入版本、job ID、費用、狀態與輸出檔位置。
只有下載並檢查成片後才能說完成，排程成功不是影片完成。

本次付費上限：[填入幣別及金額或平台 credits]。
本次允許的平台及專案：[填入]。
未填費用上限時，先完成企劃、工具查詢及支援的免費驗證，不執行付費生成。
遇到超時先查原 job，不直接重送；預設每步最多兩次修復。
缺少能力時明確說明哪一步改用 API 或人工，不把手動步驟說成已自動化。
```

## 第一階段連線盤點

```text
檢查我已連接的 Creatomate（或 Shotstack）及 ElevenLabs。
請回報：可用工具、專案範圍、素材上傳方式、4K 權限、目前費用規則。
音訊服務請確認實際有 TTS／音效工具，不能只列 Agents 管理工具。
先建立 20 秒試作的鏡頭與字幕安排，並做平台支援的 dry run。
如果缺少公開素材，列出最小缺口；不要用虛構產品圖片替代。
```

## 第二階段試作

```text
依已核准的 20 秒時間軸，以指定產品素材完成測試片。
英文與繁體中文各一個字幕圖層，測試：EDT HMI Studio、臺灣、暫存器、體驗。
先產出 1080p 預覽，保留 template/source、render ID 及費用。
旁白僅使用已核准測試句與聲音；本次不生成新的產品操作畫面。
通過預覽後，在既定預算內輸出相同內容的 4K。
下載檔案並回報實際解析度、時長、字型、音訊及待人工試看項目。
```

## 第三階段語音與音樂

```text
英語配音：clear, calm, technically credible, conversational.
不要模仿名人。用核准聲音，先試 3 個 15–20 秒片段。
EDT 與 HMI 先按單字母念法，LVGL 讀法需確認。
按 scene ID 保存原始音檔、設定及生成日期。

音樂創作描述：
Instrumental background for a concise technology product demonstration.
Restrained electronic rhythm, around 100 BPM, clean and optimistic,
subtle evolving texture, no vocals, no alarms, no cinematic impacts,
space for narration, gentle transitions, a clean ending suitable for editing.
不加入藝人、歌曲、唱片名稱或既有旋律。
先確認本公司與使用情境符合該音樂方案，再生成候選。
模型無法控制精確片長或循環時，保留足夠長度交剪輯處理。
```

## 第四階段正式剪輯

```text
依核准的 90 秒故事板與素材 manifest 建立可修改模板。
每一 scene 保留 source asset、trim、起迄、crop、雙語文字及音軌。
將實際旁白時間用來對齊字幕；不要把估計時間當最終時間碼。
一次只突出一個產品操作，字幕不遮住需要看的 UI。
先輸出 1080p 審片；列出尚未有證據的場景，不自行增添產品承諾。
審片通過後建立 30 秒版，重新安排敘事，不能直接倍速。
```

## 第五階段局部修訂與交付

```text
只修改 S05 的繁體字幕為：[指定文字]。
保持其他場景的素材、時長、字型及聲音設定不變。
先列出本次差異，再更新模板並渲染預覽；保存上一版。

通過後依交付清單輸出 90 秒／30 秒、4K／1080p、有聲／靜音版本。
保留雙語燒錄版、兩個獨立 SRT、乾淨版、聲音分軌及模板。
下載所有必要檔案，產生交付清單與 checksum。
只有實際執行過的檢查可標記完成；50 吋觀看和現場音量交人工驗收。
```
