# Claude API keys with Codex in the ChatGPT desktop app

Research date: 2026-10-25.

Follow-up: [Clients for Claude and Taiwan NCHC API credits](api-credit-alternatives.zh-TW.md) compares Cherry Studio, Cline, Continue, and Aider, with direct API configuration paths and credit eligibility distinctions.

Read the [Traditional Chinese report](README.zh-TW.md) for findings, Windows configuration considerations, and a proposed validation sequence.

A Claude API key is not a substitute for the OpenAI key described in the desktop app's [API-key sign-in documentation](https://learn.chatgpt.com/docs/auth).

The desktop app has a documented [custom gateway configuration path](https://learn.chatgpt.com/docs/enterprise/connect-to-a-gateway). Routing that gateway to Claude is a conditional integration approach, not a verified native Claude integration. The gateway must meet the [Responses compatibility requirements](https://learn.chatgpt.com/docs/enterprise/gateway-compatibility).

This research did not modify the installed app configuration or execute paid API calls. No particular Claude model or adapter has been validated.
